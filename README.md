
to set up on a local machine:
1) Use github desktop to clone a repository
2) Hit open in vscode
3) Drag .env and races.db to the Dashboard directory
4) go to search bar and type '>python:create environment' and hit enter
5) select Venv
6) Check the box on installing the reqirements
7) hit okay
8) in terminal (where venv is active) type 'streamlit run dashboard.py'
